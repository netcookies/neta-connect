安装指南

本指南将帮助你在哪吒车机或其他 Android 设备上安装哪吒互联应用。

📋 系统要求​

最低要求​

  • Android 版本: Android 11 (API 30) 或更高
  • RAM: 建议 4GB 或以上
  • 存储空间: 至少 100MB 可用空间
  • 网络: 用于下载应用和小组件（可选）

推荐配置​

  • 设备类型: 哪吒车机（完整功能支持）
  • Android 版本: Android 12 或更高
  • RAM: 6GB 或以上

兼容性说明​

  • ✅ 完整支持: 哪吒系列车型车机
  • ✅ 基础支持: 原生 Android 11+ 设备
  • ⚠️ 有限支持: 其他车机系统（部分功能可能不可用）

📥 下载应用​

方式 1: 站内 Release 页面（推荐）​

  1. 访问 Release 页面
  2. 找到当前版本的完整 APK 下载卡片
  3. 下载 NETA_CONNECT-v2.2.6.apk 文件
  4. 如需旧版本，可在同一页面的版本列表中选择对应 APK

方式 2: 从源码构建​

如果你想从源码构建应用：

# 克隆仓库
git clone https://github.com/netcookies/neta-connect.git
cd neta-connect

# 构建 Debug 版本
./gradlew assembleDebug

# 或构建 Release 版本（需要签名配置）
./gradlew assembleRelease

# APK 文件位于 app/build/outputs/apk/

📲 安装应用​

在车机上安装​

方法 1: U盘安装（推荐）​

  1. 将下载的 APK 文件复制到 U盘
  2. 将 U盘插入车机 USB 接口
  3. 使用车机的文件管理器打开 U盘
  4. 找到 APK 文件并点击安装

方法 2: 网络传输​

  1. 使用 QQ、微信等将 APK 发送到车机
  2. 在车机上打开下载的 APK 文件
  3. 点击"安装"按钮

在 Android 设备上安装​

通过 ADB 安装​

# 连接设备
adb devices

# 安装 APK
adb install NETA_CONNECT-v2.2.6.apk

# 或者强制覆盖安装
adb install -r NETA_CONNECT-v2.2.6.apk

直接安装​

  1. 将 APK 文件传输到 Android 设备
  2. 在设备上打开 APK 文件
  3. 点击"安装"按钮
  4. 如果提示"未知来源"，需要在设置中启用"允许安装未知来源应用"

🔑 授予权限​

安装完成后，首次启动应用需要授予以下权限：

必需权限​

1. 无障碍服务 ⭐（核心权限）​

用途: 实现蓝牙自动化、按键映射等核心功能

授予步骤:

  1. 打开应用后，会自动跳转到无障碍设置页面
  2. 找到"哪吒互联"服务
  3. 点击并开启无障碍服务
  4. 在弹出的对话框中点击"确定"

重要提示:

  • ⚠️ 无障碍服务是应用的核心功能，不授予此权限将无法使用大部分功能
  • ✅ 应用不会收集任何敏感信息，仅用于实现功能

2. 悬浮窗权限​

用途: 显示车辆信息悬浮窗

授予步骤:

  1. 设置 → 应用管理 → 哪吒互联
  2. 权限 → 悬浮窗权限
  3. 开启悬浮窗权限

3. 蓝牙权限​

用途: 自动控制蓝牙开关

授予步骤:

  1. 安装时会自动请求蓝牙权限
  2. 点击"允许"即可

4. 通知权限​

用途: 显示服务状态和重要提醒

授予步骤:

  1. 安装时会自动请求通知权限
  2. 点击"允许"即可

可选权限​

以下权限为可选，不影响核心功能：

  • 存储权限: 用于导出日志文件和配置备份
  • 位置权限: 某些车机系统可能需要此权限才能访问蓝牙

⚙️ 初始配置​

1. 首次启动​

启动应用后会看到欢迎页面，按照以下步骤操作：

  1. 阅读使用说明 - 了解应用的基本功能
  2. 授予权限 - 根据提示授予必要权限
  3. 完成引导 - 完成新手引导流程

2. 基础设置​

进入应用主界面后，建议进行以下配置：

配置蓝牙自动化​

  1. 进入"设置"选项卡
  2. 找到"蓝牙自动化"设置
  3. 添加需要自动开启蓝牙的应用包名
  4. 配置自动保存

启用悬浮窗​

  1. 进入"设置"选项卡
  2. 找到"悬浮窗"设置
  3. 开启悬浮窗开关
  4. 调整悬浮窗位置和透明度

配置仪表盘​

  1. 进入"仪表盘"选项卡
  2. 首次进入可点击"导入默认配置"
  3. 或者点击"+"按钮手动添加小组件
  4. 长按小组件可进入编辑模式

🔄 更新应用​

检查更新​

应用不会自动检查更新，需要手动检查：

  1. 访问 Release 页面
  2. 查看最新版本号
  3. 对比当前安装的版本
  4. 或直接进入 Release 页面 下载最新 APK

更新步骤​

  1. 下载最新版本的 APK 文件
  2. 直接安装新版本 APK
  3. 系统会自动覆盖旧版本
  4. 所有数据和配置会自动保留

注意:

  • ✅ 更新不会丢失任何数据
  • ✅ 仪表盘配置会自动保留
  • ✅ 所有设置会自动迁移

🗑️ 卸载应用​

如果需要卸载应用：

  1. 设置 → 应用管理 → 哪吒互联
  2. 点击"卸载"按钮
  3. 确认卸载

注意:

  • ⚠️ 卸载会删除所有应用数据
  • ⚠️ 建议在卸载前导出配置备份
  • ✅ 卸载不会影响系统稳定性

🐛 安装问题排查​

问题 1: 无法安装​

症状: 点击 APK 文件后无法安装

可能原因:

  • 未开启"允许安装未知来源应用"
  • 设备存储空间不足
  • APK 文件损坏

解决方法:

# 检查设备存储空间
adb shell df -h

# 检查 APK 文件完整性
shasum -a 256 NETA_CONNECT-v2.2.6.apk

# 清理缓存后重试
adb shell pm clear com.android.packageinstaller

问题 2: 安装后闪退​

症状: 应用安装后打开立即闪退

可能原因:

  • Android 版本过低（低于 Android 11）
  • 系统文件损坏
  • 权限配置问题

解决方法:

# 查看崩溃日志
adb logcat | grep -E "AndroidRuntime|FATAL"

# 清理应用数据
adb shell pm clear com.neta.isulewtools

# 重新安装
adb install -r NETA_CONNECT-v2.2.6.apk

问题 3: 无障碍服务无法开启​

症状: 在无障碍设置中找不到应用或无法开启

可能原因:

  • 系统限制
  • 应用未正确安装
  • 权限被其他安全软件拦截

解决方法:

  1. 重启设备
  2. 重新安装应用
  3. 检查是否有安全软件拦截
  4. 联系设备厂商获取支持

问题 4: 悬浮窗权限无法授予​

症状: 无法在设置中找到悬浮窗权限选项

可能原因:

  • 部分车机系统隐藏了悬浮窗权限设置
  • 系统版本过低

解决方法:

# 通过 ADB 授予悬浮窗权限
adb shell appops set com.neta.isulewtools SYSTEM_ALERT_WINDOW allow
