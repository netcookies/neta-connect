# 常见问题

本页面汇总了哪吒互联使用过程中的常见问题和解决方案。

---

## 📲 安装相关

### Q: 为什么无法安装应用？

**A**: 可能的原因和解决方法：

1. **未开启"允许安装未知来源应用"**
   - 进入设置 → 安全 → 允许安装未知来源应用
   - 找到文件管理器或浏览器，开启该选项

2. **存储空间不足**
   ```bash
   # 通过 ADB 查看存储空间
   adb shell df -h
   ```
   - 清理不需要的文件释放空间

3. **APK 文件损坏**
   - 重新下载 APK 文件
   - 验证文件完整性（检查文件大小）

4. **系统版本过低**
   - 确保 Android 版本 >= 11 (API 30)
   - 通过设置 → 关于手机查看系统版本

### Q: 安装后应用闪退怎么办？

**A**: 按以下步骤排查：

1. **查看崩溃日志**
   ```bash
   adb logcat | grep -E "AndroidRuntime|FATAL"
   ```

2. **清理应用数据**
   ```bash
   adb shell pm clear com.neta.isulewtools
   ```

3. **重新安装**
   ```bash
   adb install -r isulewTools-v1.9.2.apk
   ```

4. **检查系统版本**
   - 确保 Android 版本 >= 11

### Q: 如何通过 ADB 安装应用？

**A**: 使用以下命令：

```bash
# 1. 连接设备
adb devices

# 2. 安装 APK
adb install isulewTools-v1.9.2.apk

# 3. 如果需要覆盖安装
adb install -r isulewTools-v1.9.2.apk
```

## 🔑 权限相关

### Q: 为什么无障碍服务无法开启？

**A**: 无障碍服务是应用的核心权限，如果无法开启：

1. **在设置中找不到应用**
   - 重启设备
   - 重新安装应用
   - 检查系统是否限制了第三方应用

2. **开启后自动关闭**
   - 某些车机系统会自动关闭无障碍服务
   - 检查是否有安全软件拦截
   - 尝试添加应用到白名单

3. **权限被拒绝**
   - 联系设备厂商获取支持
   - 某些定制系统可能限制该权限

### Q: 为什么悬浮窗不显示？

**A**: 请按以下步骤检查：

1. **检查悬浮窗权限**
   - 设置 → 应用管理 → 哪吒互联
   - 权限 → 悬浮窗权限 → 开启

2. **通过 ADB 授予权限**
   ```bash
   adb shell appops set com.neta.isulewtools SYSTEM_ALERT_WINDOW allow
   ```

3. **在应用中启用悬浮窗**
   - 进入"设置"选项卡
   - 找到"悬浮窗"设置
   - 开启"显示悬浮窗"开关

4. **检查透明度设置**
   - 如果透明度设置过高，悬浮窗可能看不清
   - 调整透明度滑块到合适的值

### Q: 蓝牙无法自动控制？

**A**: 蓝牙自动化需要以下权限和配置：

1. **确认已授予权限**
   - 蓝牙权限
   - 位置权限（某些系统需要）
   - 无障碍服务权限

2. **检查蓝牙自动化配置**
   - 进入"设置"选项卡
   - 找到"蓝牙自动化"
   - 添加需要自动开启蓝牙的应用包名
   - 确保规则类型正确（白名单/黑名单）

3. **测试自动化**
   - 打开配置的应用
   - 观察蓝牙是否自动开关
   - 查看日志确认是否触发

## 🎯 仪表盘相关

### Q: 仪表盘为空怎么办？

**A**: 有两种方法添加小组件：

**方法 1: 导入默认配置**
1. 进入"仪表盘"选项卡
2. 点击"导入默认配置"按钮
3. 系统会自动添加常用小组件

**方法 2: 手动添加**
1. 点击右上角的"+"按钮
2. 从小组件列表中选择
3. 配置参数后保存

### Q: 如何调整小组件布局？

**A**: 使用拖拽功能调整：

1. **进入编辑模式**
   - 长按任意小组件

2. **调整位置**
   - 拖拽小组件到目标位置
   - 网格会自动吸附

3. **调整大小**
   - 拖拽小组件边缘
   - 支持 1×1 到 4×3 不同尺寸

4. **删除小组件**
   - 点击小组件右上角的删除按钮

5. **退出编辑**
   - 点击右上角的"完成"按钮

### Q: 小组件不显示数据怎么办？

**A**: 检查以下几点：

1. **确认数据源绑定**
   - 进入小组件配置
   - 检查数据源是否正确绑定

2. **检查车辆数据**
   - 进入"车辆数据"选项卡
   - 查看对应属性是否有值

3. **查看日志**
   - 进入"日志"选项卡
   - 搜索错误信息

4. **重启应用**
   - 某些情况下重启应用可解决问题

### Q: 如何备份仪表盘配置？

**A**: 使用配置导出功能：

1. 进入"设置" → "高级设置"
2. 点击"备份配置"
3. 选择保存路径
4. 配置会保存为 JSON 文件

**恢复配置**:
1. 进入"设置" → "高级设置"
2. 点击"恢复配置"
3. 选择备份的 JSON 文件
4. 应用会自动重启并加载配置

## 🔌 插件和小组件商店

### Q: 为什么安装的小组件找不到？

**A**: 按以下步骤检查：

1. **确认是否已重启应用**
   - 安装小组件后必须重启应用
   - 完全退出应用后重新打开

2. **检查应用版本**
   - 确认应用版本满足小组件的最低要求
   - 进入"关于"查看当前版本

3. **查看已安装列表**
   - 进入"高级" → "已安装小组件"
   - 确认小组件是否在列表中

4. **查看加载日志**
   ```bash
   adb logcat | grep -E "WidgetLoader|WidgetManager"
   ```

### Q: 小组件下载失败怎么办？

**A**: 尝试以下方法：

1. **检查网络连接**
   - 确保设备可以访问 GitHub
   - 尝试使用其他网络

2. **刷新商店列表**
   - 退出商店后重新进入
   - 尝试重启应用

3. **手动安装**
   - 从 [GitHub](https://github.com/netcookies/neta-connect/tree/main/widgets) 下载 JAR 文件
   - 使用 ADB 推送到设备：
     ```bash
     adb push your-widget.jar /sdcard/Download/neta_connect/
     ```
   - 重启应用

### Q: 如何卸载小组件？

**A**: 有两种方法：

**方法 1: 从商店卸载**
1. 进入"高级" → "小组件商店"
2. 找到已安装的小组件
3. 点击"卸载"按钮
4. 确认并重启应用

**方法 2: 从已安装列表卸载**
1. 进入"高级" → "已安装小组件"
2. 找到要卸载的小组件
3. 点击"卸载"按钮
4. 确认并重启应用

**注意**:
- ⚠️ 卸载小组件后，仪表盘中使用该小组件的实例会被自动移除
- ⚠️ 建议在卸载前备份仪表盘配置

### Q: 可以同时安装多个版本的小组件吗？

**A**: 不可以。每个小组件只能安装一个版本。更新会自动替换旧版本。

## 📊 车辆数据相关

### Q: 为什么车辆数据显示为空？

**A**: 可能的原因：

1. **车辆未启动**
   - 确保车辆已启动或通电
   - 某些数据只在车辆运行时可用

2. **数据权限问题**
   - 部分车型可能限制了某些数据访问
   - 查看日志确认是否有权限错误

3. **VHAL 连接问题**
   - 重启应用尝试重新连接
   - 查看日志中的 VHAL 相关信息

### Q: 如何添加自定义数据源？

**A**: 按以下步骤创建：

1. 进入"车辆数据"选项卡
2. 点击"添加自定义数据源"
3. 输入数据源名称（如"功率"）
4. 输入公式（如 `电压 × 电流 ÷ 1000`）
5. 选择源数据属性
6. 保存后可在仪表盘中使用

**支持的运算符**:
- `+` 加法
- `-` 减法
- `×` 乘法
- `÷` 除法
- `()` 括号改变优先级

### Q: 如何为数据添加标签？

**A**: 使用标签管理功能：

1. 在车辆数据页面点击任意属性
2. 点击"添加标签"
3. 输入标签名称（如"重点关注"）
4. 保存后可通过标签筛选数据

## 🛠️ 系统功能相关

### Q: 方向盘按键映射不工作？

**A**: 检查以下配置：

1. **确认无障碍服务已开启**
   - 这是按键映射的必需权限

2. **检查支持的应用**
   - 网易云音乐
   - QQ音乐
   - 酷狗音乐
   - 酷我音乐

3. **测试按键**
   - 打开支持的音乐应用
   - 按下方向盘上的媒体控制键
   - 查看日志确认是否捕获到按键事件

### Q: 如何获取应用包名？

**A**: 使用以下方法：

**方法 1: 通过 ADB**
```bash
# 列出所有已安装应用
adb shell pm list packages | grep 应用名

# 查看当前前台应用
adb shell dumpsys window | grep mCurrentFocus
```

**方法 2: 常用应用包名**
| 应用名称 | 包名 |
|---------|------|
| 网易云音乐 | `com.netease.cloudmusic` |
| QQ音乐 | `com.tencent.qqmusic` |
| 酷狗音乐 | `com.kugou.android` |
| 高德地图 | `com.autonavi.minimap` |
| 百度地图 | `com.baidu.BaiduMap` |

## 🐛 日志和调试

### Q: 如何导出日志？

**A**: 使用应用内导出功能：

1. 进入"日志"选项卡
2. 点击右上角的"导出"按钮
3. 选择导出路径
4. 日志会保存为文本文件

**或通过 ADB 导出**:
```bash
# 导出应用日志
adb logcat -d | grep "NetaConnect" > neta_log.txt

# 导出完整系统日志
adb logcat -d > system_log.txt
```

### Q: 如何查看崩溃日志？

**A**: 使用 ADB 命令：

```bash
# 实时查看崩溃信息
adb logcat | grep -E "AndroidRuntime|FATAL"

# 查看特定应用的日志
adb logcat | grep "com.neta.isulewtools"

# 查看小组件加载日志
adb logcat | grep -E "WidgetLoader|WidgetManager"
```

## ⚙️ 高级设置

### Q: 如何切换深色/浅色模式？

**A**: 在主题设置中切换：

1. 进入"设置"选项卡
2. 点击"高级设置"
3. 选择"主题管理"
4. 选择：
   - 跟随系统
   - 浅色模式
   - 深色模式

### Q: 如何重置所有设置？

**A**: 使用重置功能：

1. 进入"设置" → "高级设置"
2. 点击"重置设置"
3. 确认重置
4. 所有配置恢复默认值

**注意**: ⚠️ 重置会清除所有自定义配置，建议先备份

### Q: 如何清理应用缓存？

**A**: 有两种方法：

**方法 1: 应用内清理**
1. 进入"设置" → "高级设置"
2. 点击"清理缓存"
3. 释放存储空间

**方法 2: 系统设置清理**
1. 设置 → 应用管理 → 哪吒互联
2. 存储 → 清理缓存

## 🚗 设备兼容性

### Q: 支持哪些设备？

**A**: 兼容性说明：

- ✅ **完整支持**: 哪吒系列车型车机
- ✅ **基础支持**: 原生 Android 11+ 设备
- ⚠️ **有限支持**: 其他车机系统（部分功能可能不可用）

**最低要求**:
- Android 11 (API 30) 或更高
- 4GB RAM（推荐 6GB+）
- 100MB 可用存储空间

### Q: 在非哪吒车机上能用吗？

**A**: 可以安装和使用，但：

1. **功能限制**
   - 车辆数据监控功能可能不可用
   - 依赖 VHAL 的功能需要设备支持

2. **可用功能**
   - 仪表盘系统
   - 插件系统
   - 蓝牙自动化
   - 按键映射（如果设备支持）

3. **建议**
   - 在安装前查看功能列表
   - 确认核心功能是否满足需求

## 🔄 更新相关

### Q: 如何检查应用更新？

**A**: 手动检查更新：

1. 访问 [GitHub Releases](https://github.com/netcookies/isulewTools/releases)
2. 查看最新版本号
3. 对比当前安装的版本
4. 下载最新版本的 APK

### Q: 更新会丢失数据吗？

**A**: 不会。更新过程中：

- ✅ 所有数据和配置会自动保留
- ✅ 仪表盘配置会自动保留
- ✅ 所有设置会自动迁移
- ✅ 已安装的小组件会保留

**建议**: 更新前仍建议备份配置，以防万一
