# 使用指南

本指南将帮助你快速上手哪吒互联的各项功能。

---

## 🚀 快速开始

### 首次使用流程

1. **启动应用** - 打开哪吒互联应用
2. **授予权限** - 根据提示授予无障碍、悬浮窗等权限
3. **完成引导** - 跟随新手引导了解基本功能
4. **开始使用** - 进入主界面开始使用

### 主界面介绍

应用采用底部导航栏设计，包含以下选项卡：

- **主页** - 应用概览和快捷操作
- **仪表盘** - 自定义车辆数据仪表盘
- **车辆数据** - 查看实时车辆数据
- **设置** - 应用配置和高级设置

---

## 🎯 仪表盘使用

### 添加小组件

1. 进入"仪表盘"选项卡
2. 点击右上角的"+"按钮
3. 从小组件列表中选择需要的小组件
4. 配置小组件参数
5. 点击"保存"添加到仪表盘

### 编辑小组件布局

1. **进入编辑模式**: 长按任意小组件
2. **调整位置**: 拖拽小组件到目标位置
3. **调整大小**: 拖拽小组件边缘调整大小
4. **删除小组件**: 点击小组件右上角的删除按钮
5. **配置参数**: 点击齿轮图标修改小组件参数
6. **退出编辑**: 点击右上角的"完成"按钮

### 导入默认配置

如果仪表盘为空，可以快速导入默认配置：

1. 进入"仪表盘"选项卡
2. 点击"导入默认配置"按钮
3. 系统会自动添加常用小组件
4. 可以根据需要调整布局

### 小组件类型说明

#### 信息卡片
- **4×3 (3列)**: 显示3项数据，适合展示电压、电流、功率等
- **4×3 (4列)**: 显示4项数据，信息密度更高
- **4×2 (2列)**: 显示2项数据，紧凑布局

#### 图表类
- **折线图**: 显示数据趋势，支持实时更新
- **柱状图**: 对比多个数据项
- **圆形进度表**: 显示百分比数据（如电量）
- **温度计**: 垂直温度显示

#### 实用工具
- **电池组件**: 电量显示，支持多种样式
- **胎压监测**: 四轮胎压实时监控
- **进度条**: 线性进度显示

## 🔧 系统功能配置

### 蓝牙自动化

#### 配置方法

1. 进入"设置"选项卡
2. 找到"蓝牙自动化"设置
3. 点击"添加应用"
4. 输入应用包名（如 `com.netease.cloudmusic`）
5. 选择规则类型：
   - **白名单**: 打开指定应用时自动开启蓝牙
   - **黑名单**: 打开指定应用时自动关闭蓝牙

#### 常用应用包名

| 应用名称 | 包名 |
|---------|------|
| 网易云音乐 | `com.netease.cloudmusic` |
| QQ音乐 | `com.tencent.qqmusic` |
| 酷狗音乐 | `com.kugou.android` |
| 高德地图 | `com.autonavi.minimap` |
| 百度地图 | `com.baidu.BaiduMap` |

#### 获取应用包名

如果不知道应用的包名，可以通过以下方法获取：

```bash
# 方法 1: 列出所有已安装应用
adb shell pm list packages | grep 应用名

# 方法 2: 查看当前前台应用
adb shell dumpsys window | grep mCurrentFocus
```

### 悬浮窗配置

#### 开启悬浮窗

1. 进入"设置"选项卡
2. 找到"悬浮窗"设置
3. 开启"显示悬浮窗"开关
4. 悬浮窗会立即显示

#### 调整悬浮窗

- **移动位置**: 单指拖拽悬浮窗
- **调整大小**: 双指缩放悬浮窗
- **调整透明度**: 在设置中调整透明度滑块
- **显示内容**: 选择要在悬浮窗中显示的数据项

### 按键映射（方向盘按键）

哪吒互联支持将方向盘媒体控制按键映射到主流音乐APP：

#### 支持的应用

- 网易云音乐
- QQ音乐
- 酷狗音乐
- 酷我音乐

#### 配置方法

1. 确保无障碍服务已开启
2. 打开支持的音乐应用
3. 按下方向盘上的媒体控制键
4. 应用会自动适配按键功能

#### 按键功能

- **播放/暂停**: 播放或暂停音乐
- **下一曲**: 切换到下一首歌
- **上一曲**: 切换到上一首歌
- **音量加/减**: 调整音量

## 📊 车辆数据监控

### 查看实时数据

1. 进入"车辆数据"选项卡
2. 查看所有可用的车辆属性
3. 支持的数据包括：
   - 电池电量（%）
   - 电压（V）
   - 电流（A）
   - 功率（kW）
   - 车速（km/h）
   - 续航里程（km）
   - 温度（℃）
   - 胎压（kPa）

### 添加自定义标签

为常用的车辆属性添加标签，方便快速筛选：

1. 在车辆数据页面点击任意属性
2. 点击"添加标签"
3. 输入标签名称（如"重点关注"）
4. 保存后可通过标签筛选数据

### 使用自定义数据源

创建虚拟属性，通过公式计算：

1. 进入"车辆数据"选项卡
2. 点击"添加自定义数据源"
3. 输入数据源名称（如"功率"）
4. 输入公式（如 `电压 × 电流 ÷ 1000`）
5. 选择源数据属性
6. 保存后可在仪表盘中使用

#### 支持的运算符

- `+` 加法
- `-` 减法
- `×` 乘法
- `÷` 除法
- `()` 括号改变优先级

## 🔌 小组件商店

### 浏览小组件

1. 进入"高级"选项卡
2. 点击"小组件商店"
3. 浏览可用的小组件列表
4. 查看小组件详情和截图

### 安装小组件

1. 在小组件商店中找到需要的小组件
2. 点击"安装"按钮
3. 等待下载完成
4. 自动安装到应用中
5. 重启应用后可在仪表盘编辑器中使用

### 管理已安装小组件

1. 进入"高级"选项卡
2. 点击"已安装小组件"
3. 查看所有已安装的小组件
4. 可以卸载不需要的小组件

### 更新小组件

1. 小组件商店会显示可更新的小组件
2. 点击"更新"按钮
3. 下载并安装新版本
4. 重启应用后生效

## 🐛 日志查看

### 查看系统日志

1. 进入"日志"选项卡
2. 查看实时系统日志
3. 支持的日志级别：
   - **INFO**: 一般信息
   - **DEBUG**: 调试信息
   - **WARN**: 警告信息
   - **ERROR**: 错误信息

### 筛选日志

- **按级别筛选**: 选择要显示的日志级别
- **按标签筛选**: 选择特定的日志标签
- **搜索关键词**: 输入关键词快速查找

### 导出日志

1. 点击右上角的"导出"按钮
2. 选择导出路径
3. 日志会保存为文本文件
4. 可用于问题反馈

---

## ⚙️ 高级设置

### 主题管理

1. 进入"设置"选项卡
2. 点击"高级设置"
3. 选择"主题管理"
4. 可选：
   - **跟随系统**: 自动切换深浅色模式
   - **浅色模式**: 始终使用浅色主题
   - **深色模式**: 始终使用深色主题

### 配置备份与恢复

#### 备份配置

1. 进入"设置" → "高级设置"
2. 点击"备份配置"
3. 选择保存路径
4. 所有配置会保存为 JSON 文件

#### 恢复配置

1. 进入"设置" → "高级设置"
2. 点击"恢复配置"
3. 选择之前备份的 JSON 文件
4. 确认恢复
5. 应用会自动重启并加载配置

### 数据管理

#### 清理缓存

1. 进入"设置" → "高级设置"
2. 点击"清理缓存"
3. 释放存储空间

#### 重置设置

1. 进入"设置" → "高级设置"
2. 点击"重置设置"
3. 确认重置
4. 所有配置恢复默认值

## 📝 使用技巧

### 仪表盘技巧

- 长按小组件快速进入编辑模式
- 拖拽小组件到屏幕边缘可调整网格布局

- 悬浮窗支持显示多个数据项

- 白名单模式适合大部分场景
- 黑名单模式用于特定应用需要关闭蓝牙
- 可以为同一应用设置多个规则

### 数据监控技巧

- 使用标签管理常用数据
- 自定义数据源可计算复杂指标
- 日志功能帮助诊断问题
