小组件商店

哪吒互联小组件商店提供官方和社区开发的小组件插件，让你可以轻松扩展仪表盘功能。

🏪 商店功能​

浏览小组件​

  1. 打开哪吒互联应用
  2. 进入"高级"选项卡
  3. 点击"小组件商店"
  4. 浏览可用的小组件列表

小组件信息​

每个小组件显示以下信息：

  • 名称和图标 - 小组件的显示名称和图标
  • 版本号 - 当前最新版本
  • 作者 - 开发者名称
  • 描述 - 功能说明
  • 状态 - STABLE（稳定）/ BETA（测试）/ DEPRECATED（已弃用）
  • 最低应用版本 - 需要的最低应用版本

⬇️ 安装小组件​

从商店安装​

  1. 在小组件列表中找到需要的小组件
  2. 点击小组件卡片查看详情
  3. 点击"安装"按钮
  4. 等待下载完成（显示进度）
  5. 安装成功后会显示提示
  6. 重启应用以加载新小组件

验证安装​

安装后，你可以：

  1. 进入"仪表盘"选项卡
  2. 点击"+"添加小组件
  3. 在小组件列表中查看新安装的小组件

🔄 更新小组件​

检查更新​

  1. 进入"小组件商店"
  2. 已安装的小组件如有更新会显示"更新"按钮
  3. 版本号旁会显示"有更新"标志

更新流程​

  1. 点击"更新"按钮
  2. 下载新版本
  3. 自动替换旧版本
  4. 重启应用以加载新版本

🗑️ 卸载小组件​

卸载方法 1: 从商店卸载​

  1. 进入"小组件商店"
  2. 找到已安装的小组件
  3. 点击"卸载"按钮
  4. 确认卸载
  5. 重启应用以移除小组件

卸载方法 2: 从已安装列表卸载​

  1. 进入"高级"选项卡
  2. 点击"已安装小组件"
  3. 找到要卸载的小组件
  4. 点击"卸载"按钮
  5. 确认卸载
  6. 重启应用

注意:

  • ⚠️ 卸载小组件后，仪表盘中使用该小组件的实例会被自动移除
  • ⚠️ 卸载前建议先备份仪表盘配置

📦 可用小组件​

官方小组件​

信息展示类​

信息卡片 4×3（3列） - widget-info-card-4x3d3

  • 显示3项数据，适合宽屏显示
  • 支持自定义标题、单位和颜色
  • 可绑定任意车辆数据源

信息卡片 4×3（4列） - widget-info-card-4x3d4

  • 显示4项数据，信息密度更高
  • 适合显示电池电压、电流、功率等关键数据

信息卡片 4×2（2列） - widget-info-card-4x2d2

  • 显示2项数据，紧凑布局
  • 适合小屏幕或需要更多小组件的场景

图表类​

折线图 - widget-line-chart

  • 实时趋势展示
  • 支持数据历史回溯
  • 可自定义时间范围和Y轴范围

柱状图 - widget-bar-chart

  • 对比数据可视化
  • 支持多个数据项对比
  • 可自定义颜色和标签

仪表盘类​

圆形进度表 - widget-arc-gauge

  • 百分比数据展示
  • 支持自定义颜色和范围
  • 适合显示电量、速度等

温度计 - widget-temperature

  • 垂直温度显示
  • 支持摄氏度和华氏度
  • 可自定义温度范围

实用工具类​

电池组件 - widget-battery

  • 电量显示，支持多种样式
  • 实时显示充电状态
  • 可自定义颜色

胎压监测 - widget-tire-pressure

  • 四轮胎压实时监控
  • 支持异常提醒
  • 可自定义安全范围

进度条 - widget-progress-bar

  • 线性进度显示
  • 支持横向和纵向
  • 可自定义颜色和标签

🔧 商店配置​

索引 URL​

商店默认使用以下索引：

https://raw.githubusercontent.com/netcookies/neta-connect/main/widgets/index.json

自定义索引（高级）​

如果你想使用自定义的小组件索引：

  1. 进入"设置" → "高级设置"
  2. 找到"小组件商店设置"
  3. 输入自定义索引 URL
  4. 点击"保存"
  5. 返回商店刷新列表

📥 手动安装小组件​

如果无法使用商店，可以手动安装：

步骤 1: 下载 JAR 文件​

从 GitHub 下载小组件 JAR 文件：

https://github.com/netcookies/neta-connect/tree/main/widgets

步骤 2: 传输到设备​

使用 ADB 或文件管理器：

# 使用 ADB
adb push your-widget.jar /sdcard/Download/neta_connect/

# 或通过文件管理器
# 将 JAR 文件复制到 /sdcard/Download/neta_connect/ 目录

步骤 3: 重启应用​

重启哪吒互联应用，小组件会自动加载。

🐛 常见问题​

Q: 为什么安装后找不到小组件？​

A:

  1. 确认是否已重启应用
  2. 检查应用版本是否满足最低要求
  3. 查看日志确认加载状态
adb logcat | grep -E "WidgetLoader|WidgetManager"

Q: 小组件下载失败怎么办？​

A:

  1. 检查网络连接
  2. 尝试刷新商店列表
  3. 使用手动安装方式

Q: 如何找回被卸载的小组件？​

A:

  1. 进入"小组件商店"
  2. 重新下载并安装
  3. 之前的配置会丢失，需要重新配置

Q: 可以同时安装多个版本吗？​

A: 不可以。每个小组件只能安装一个版本。更新会自动替换旧版本。

  1. 开发插件 - 参考 插件开发指南
